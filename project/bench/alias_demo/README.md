# alias_demo

用耳朵驗證 aliasing。**訊號源是板子自己產生的掃頻正弦波，不碰輸入**——
所以在 codec ADC 修好之前也能跑（輸出鏈路已於 2026-09-06 19:00 驗過）。

八秒一趟，兩種模式交替：

- **CLEAN**：純正弦掃頻，不削波。只有一個音，從低往高。這是對照組。
- **CLIP**：×20 灌進 hard clip，再 ×0.2 拉回安全音量。

聽什麼：CLIP 那趟一往上掃，就會有東西**往下掉**。
削波產生的諧波全部是往上跑的，任何下行的成分只可能是超過 Nyquist
折返回來的——折返本來就是反向的，這是 alias 唯一無法偽裝的特徵。

接線：pin18 → Tip、pin20 → Sleeve → EVO 4 Line In。輸入端不需要接。
序列埠每 250ms 印一行當前模式與頻率。
